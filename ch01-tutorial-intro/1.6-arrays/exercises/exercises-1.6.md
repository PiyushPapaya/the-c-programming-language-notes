# Exercises: 1.6 Arrays

These are the exercises found in the section text. Check one off when you have a
working solution file for it in this folder.

Solution files go next to this file and are named like `ex1-6a.c`, `ex1-6b.c`
(that is `ex<chapter>-<section><letter>.c`).

Total exercises: 2

- [ ] **Exercise 1-13 (a).** Write a program to print a histogram of the lengths of words in its input. It is easy to draw the histogram with the bars horizontal; a vertical orientation is more challenging.
- [ ] **Exercise 1-14 (b).** Write a program to print a histogram of the frequencies of different characters in its input.
