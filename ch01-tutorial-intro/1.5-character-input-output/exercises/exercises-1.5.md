# Exercises: 1.5 Character Input and Output

These are the exercises found in the section text. Check one off when you have a
working solution file for it in this folder.

Solution files go next to this file and are named like `ex1-5a.c`, `ex1-5b.c`
(that is `ex<chapter>-<section><letter>.c`).

Total exercises: 7

- [x] **Exercise 1-6 (a).** Verify that the expression `getchar() != EOF` is 0 or 1.
- [x] **Exercise 1-7 (b).** Write a program to print the value of `EOF`.
- [x] **Exercise 1-8 (c).** Write a program to count blanks, tabs, and newlines.
- [x] **Exercise 1-9 (d).** Write a program to copy its input to its output, replacing each string of one or more blanks by a single blank.
- [x] **Exercise 1-10 (e).** Write a program to copy its input to its output, replacing each tab by `\t`, each backspace by `\b`, and each backslash by `\\`. This makes tabs and backspaces visible in an unambiguous way.
- [x] **Exercise 1-11 (f).** How would you test the word count program? What kinds of input are most likely to uncover bugs if there are any?
- [x] **Exercise 1-12 (g).** Write a program that prints its input one word per line.
